本版重点：你报的四个问题全部查到根因并修掉，另修了一个会裁掉半页字的隐患

【1】地脚（页码/时间/电池）跑到屏幕顶端
  根因是代码结构，不是渲染玄学：PageFooterBar 被写在正文那个 Box 里面，
  而 Box 默认对齐是左上 —— 于是它被画到屏幕最顶端，与系统状态栏的电池
  图标并排。注释里写着「它是 Column 的第二个子项」，代码却不是。
  另外 .height(26.dp) 写在 .padding(bottom = safeBottom) 之前，
  手势条的安全区把那 26dp 整个吃掉，文字被挤出容器只露半截。
  现在：真正的 Column 第二个子项 + padding 在外、height 在内。

【2】覆盖模式要点两下才能翻页
  有两层手势同时处理点击：一次点击被处理两遍（中间热区切两次=没反应，
  左右热区连翻两页）。更致命的是旧代码结尾那个「等手指全部抬起」的循环：
  它在手指已经抬起之后才开始等，于是**下一次点击被整个吃掉**。
  现在：整个阅读页只有一层手势，且全程不消费事件。

【3】滚动模式滚不动
  正文是 BasicTextField / SelectionContainer，两者都会抢走整条手势流，
  和 verticalScroll 互斥。现在正文是普通 Text，自身不带任何手势。

【4】滚动模式底部被手势条压住
  留白必须在 verticalScroll 之后（属于滚动内容），滚到底最后一行才会
  停到手势条之上；写在之前就成了容器的内边距，最后一行永远压在下面。

【5】按你的要求删掉长按选词
  正文不再有任何选区手势。连带影响：查词与划线原本唯一的入口就是长按取词，
  现在它们没有入口了（功能代码还在，没删）。需要的话下轮给它们单独的入口。

【6】顺带找到并修掉一个会裁字的隐患
  分页量的是原始正文，而渲染会插首行缩进与段落空行 —— 段间距调到 2 个
  空行时，一页十几个段落就多出十几行，版心装不下，末页被裁掉小半页。
  现在分页量的是「渲染后的字符串」，页边界再映射回章内偏移，坐标系不变。
  新增 4 条回归测试守住这条不变量（把任意一页按渲染规则重排必须仍是一页）。

按审计结果补齐的「假功能」（有开关、没实现）
  - 音量键翻页：全项目没有任何按键处理。现在接到 Activity.onKeyDown，
    音量减=下一页、音量加=上一页，退出阅读页自动还原。
  - 「重新阅读」与「继续阅读」行为完全相同。现在真的从第一章开头开始。
  - 列表布局下没有「移到分组」入口（网格有）。已补上，长按即出。
  - 滚动模式从不更新页码：滚着读了三千字，退出后再打开回到本章开头。
    现在按滚动位置折算页码，进度、百分比与持久化全部跟着对。
  - 排版面板缺首行缩进 / 字间距 / 加粗 / 两端对齐四项（setter 全项目零调用）。
    已补齐；段间距改成按「空行数」调，不再是一个按了没反应的倍率。
  - 段间距与两端对齐没进分页缓存键，改了不重排。已加入。
  - 「清除全部数据」不清分组与自定义词典，且没有任何反馈。已补齐并有提示。
  - 导入完成后无法直接开始阅读（要手动返回→书库→详情→开始阅读）。
    现在导入完成即可一键开始，并把导入页从返回栈里摘掉。
  - 自定义词典导入是死代码（有个永远不会被点到的「删除」）。已接上文件选择器。
  - 应用内可见文字全部改成中文：应用名 Reader → 墨鱼阅读、
    Material You 动态取色 → 动态取色（跟随壁纸）、朗读（TTS）→ 朗读、
    封面角标 TXT/EPUB/PDF → 文本/电子书/PDF 文档。

顺带修掉的会崩溃的地方

    Compose Slider 会直接抛异常崩溃。现在单章时禁用该滑杆。
