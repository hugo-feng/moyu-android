本版修复
  1. 书籍详情页：书库里点书先进详情页，可「加入书架 / 笔记 / 删除 /
     开始阅读 / 看目录」。此前书库点书直接进阅读器，
     导致完全没有入口把书加入书架
  2. 分页把句子从中间切开：断行策略两侧统一为质量优先
  3. 分页底部留一大块空白：行高两侧口径统一为
     「期望行高与字体自然行高的较大值」
  4. 滚动模式一滚就弹控制栏：位移超过触摸阈值就不算点击
  5. 顶栏书名改为左对齐
  6. 书库/书架的封面「只有色块」：封面尺寸改为显式计算，
     不再依赖 aspectRatio（宽度约束未定时它会退化成正方形）
  7. 书架首页只显示分组卡，点进去才看书
  8. 分组卡长按可重命名/删除
  9. 阅读设置面板重排为 外观/文字/翻页/自动阅读 四段
 10. 书库主页移除统计数字、继续阅读、导入按钮；搜索栏移到顶部
 11. 字体选项改为 6 种真实可区分的「族 × 字重」组合
     （原先「楷体/思源宋/黑体」三项都映射到同样两个族，且只显示前三个）
 12. 分页引擎改用与渲染相同的字体（此前是 Typeface.DEFAULT，
     字体不同会导致换行位置不同、分页与显示错位）
