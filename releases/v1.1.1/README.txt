本版重点：已导入的书会自动重新分章

  你那本《空蝉》已经导入过，章节是旧规则切的（3 万字被按
  3000 字一块切成十几节）。只改规则是没用的 —— 你装上新包后
  看到的仍然会是旧的目录。而删掉重新导入也不行：
  判重按「标题 + 字数」比对，会被判为重复直接返回，章节不会重算。

  所以这一版给分章结果打了版本号：
    - 数据库升级（3 → 4），给书加 split_version 字段
    - 打开某本书时若版本落后，就用库里存的章节正文重建全文、
      按新规则重切一次
    - 重建前后校验总长度一致，不一致就放弃替换
      （换错会让阅读位置指向别处，比不换更糟）

  预期效果：装上后打开《空蝉》，目录应该变成
  序幕邂逅 / 第一幕憧憬 / 第二幕赔偿损失 这样的几条，
  而不是十几个「第 N 节」。

  注意：这是**首次真正验证重新分章**。若目录没变，
  请告诉我（可能是重建校验没通过而主动放弃了替换）。

同时包含上一版的内容
  - 分章规则补入「幕」「场」「序幕」，允许无空格连接
  - 滚动模式修根因（点击层不再消费拖动）
  - 地脚改为独立底栏
  - 删除笔记功能，只保留书签
  - 书库适配状态栏、分组卡固定高度
