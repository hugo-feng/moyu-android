  3. 底部工具栏从六个按钮瘦到三个：目录 / 笔记 / 设置
  4. 「排版」改名「设置」；夜间与自动阅读并入该面板
  5. 搜索与书签移到顶栏右上角
  6. 长按文字写笔记：改用 BasicTextField 的原生选区
     （上一版挂在 SelectionContainer 上的手势会被它抢走，
      真机上长按毫无反应 —— 这次修的是根因）
