本版变更
  1. 正文底部再留半行安全余量（防「最后一行被切一半」）
     上一版按实测高度分页已修掉「整章被当成一页」的严重缺陷，
     但字形下缘（descent）与容器底边仍可能差几像素，最后一行被切。
     现在两页都再扣掉半行，同时作用于分页判定与容器高度校验。
     顺带修正 estimateCharsPerScreen 未扣该余量、导致预估页数偏少。
  2. 电量改为图标（电池轮廓 + 按容量填充），不再显示百分比数字。
     自己用 Canvas 画，不新增资源文件；未拿到电量时只画空壳，
     不会显示成 0% 让人误以为没电。

注意：本包从未在真机或模拟器上运行过。
