本版重点
  1. 滚动模式失效（重点验证）
     根因：盖在阅读区上的点击层用了 detectTapGestures，
     它一旦挂上就会消费手势流，正文的 verticalScroll 收不到拖动。
     现改为手写判定：位移超过 touchSlop 就完全不消费事件，
     交给滚动层。请验证「上下滑动能正常滚动」+
     「轻点一下能呼出/收起工具栏」两件事都对。

  2. 地脚改为独立底栏
     页码/时间/电量原先是页面内容的最后一个子项，位置取决于
     正文区 height 的隐式推算；正文被压成 0 高时它顶到了屏幕最上方
     （你截图里 app 电池与系统电池并排就是证据）。
     现改为两段式：正文层 weight(1f) + 独立地脚。

  3. 删除笔记功能，只保留书签
     底栏「书签」按钮打开本书书签列表；顶部栏右侧图标为当前页加书签。
     长按选词写笔记那条路已全部移除（真机上始终不可用）。
     划线数据仍保留在数据库，只是没有界面入口。

  4. 书架行图标区分
     「加入书架」与「本书书签」原先都是书签图标，现改为不同图标。

  5. 书库适配状态栏
  6. 分组卡固定高度（原先前面的色块把名称与本数挤出卡片）
  7. 分章新增尾部判据，挡住「第1节的故事从这里开始」这类句子中间的误判
