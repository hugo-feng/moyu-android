本版重点

  1. 短篇被切成多节 —— 真正原因已找到并修复
     你的文件（空蝉）是**剧本体例**：序幕邂逅 / 第一幕憧憬 / 第二幕赔偿损失。
     而分章量词表只有「章节回卷节篇部集话」，没有「幕」「场」；
     「序幕」也不在特殊篇名里，且要求标记与描述间有空格，
     而文件里写的是「序幕邂逅」（无空格）。

     结果：整篇一个标题都认不出来，走了「按 3000 字均匀切块」的兜底，
     3 万字被切成约 10 节。这与「误判成很多节」方向正好相反。

     现已补入「幕」「场」「序幕」，并允许无空格连接。

  2. 滚动模式
     根因是盖在阅读区上的点击层用了 detectTapGestures，
     它一挂上就消费手势流，正文的 verticalScroll 收不到拖动。
     现改为手写判定：位移超过 touchSlop 即完全不消费事件。

  3. 地脚改为独立底栏（页码/时间/电量不再出现在屏幕顶部）

  4. 删除笔记功能，只保留书签

请重点验证
  a) 滚动模式：上下滑能滚吗？轻点能呼出/收起工具栏吗？（两个都要）
  b) 空蝉这本书的目录：现在应该只有几个条目（序幕 + 各幕），
     而不是十几个「第 N 节」
  c) 书签：顶栏右侧加书签 → 底栏「书签」能看到列表吗？
  d) 页码/时间/电量是否还在屏幕顶部
